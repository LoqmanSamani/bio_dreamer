# BioDreamer — Web Interface Guide

> User manual for the BioDreamer web application. Covers navigation, input
> formats, interactive visualisations, and job management.
>
> ## Sections to write
>
> 1. **Dashboard** — Overview of the landing page: module cards (MolDreamer, ProteinDreamer, CellDreamer), recent jobs, model status.
> 2. **ProteinDreamer Page** — Input form (wild-type sequence, PDB upload, objective selection), parameter tuning (number of dream steps, mutation budget, exploration weight), output interpretation (3D protein viewer, mutation trajectory, fitness landscape plot, candidate table).
> 3. **MolDreamer Page** — PDB/SDF upload, trajectory visualisation, property evolution plots.
> 4. **CellDreamer Page** — Gene expression upload (CSV/h5ad), target state definition, perturbation plan visualisation, gene heatmap.
> 5. **Model Hub** — Browse available models (local + HF Hub), load/unload models, view model cards, upload custom models.
> 6. **Job Tracker** — View running/completed/failed jobs, inspect logs, download results.
> 7. **3D Viewers** — How to interact with Mol*/NGL protein and molecule viewers (rotate, zoom, select residues, colour by property).
