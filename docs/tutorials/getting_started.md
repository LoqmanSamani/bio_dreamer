# BioDreamer — Getting Started Tutorial

> Step-by-step guide to setting up BioDreamer locally, running your first
> protein design job, and understanding the output.
>
> ## Sections to write
>
> 1. **Installation** — Clone repo, install Python deps (pip install -e .), install frontend deps (npm install).
> 2. **Download Pre-trained Models** — Pull default world models from Hugging Face Hub.
> 3. **Start the Platform** — `make dev` to launch backend + frontend.
> 4. **Your First ProteinDreamer Job** — Enter a wild-type sequence, select fitness objective, run "Dream" → watch the agent plan mutation paths in imagination.
> 5. **Understanding the Output** — Mutation trajectory visualisation, fitness plot, ranked candidate list, uncertainty estimates.
> 6. **Your First MolDreamer Job** — Upload a PDB file, select a property to optimise, run latent MD rollouts.
> 7. **Your First CellDreamer Job** — Upload a gene expression profile, define a target cell state, run perturbation planning.
> 8. **Next Steps** — Links to training guide, API reference, and advanced configuration.
